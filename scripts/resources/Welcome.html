This installs GNU Make, built to run on Mac OS X 10.9 (Mavericks) and later, Intel and Apple Silicon alike, into /usr/local/mavergreen/make/. It needs no Command Line Tools.

Open a new Terminal window: gmake and make are on your PATH. Your shell searches /usr/bin first, so a bare make still finds Apple's, which without the Command Line Tools only offers to install them: call gmake, or /usr/local/mavergreen/bin/make.

A background updater (Sparkle) checks daily for new releases. Built from GNU's source, unmodified, with the recipe at github.com/Mavergreen/make. This is an unofficial community build, not affiliated with or supported by the GNU Project or the Free Software Foundation.
